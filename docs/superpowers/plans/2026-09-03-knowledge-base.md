# Knowledge Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the agent something to answer from — a per-agent store of short, quotable facts, searchable in Russian, filled by hand or imported from pasted text and a web page.

**Architecture:** One row is one retrievable answer. Postgres generates a `tsvector` over the title and content, a GIN index makes it fast, and one `searchKnowledge()` function is the only way anything reads it — so stage 5 can add embeddings behind that signature without touching a route or a screen. The one outbound fetch goes through an interface the tests replace, the same way the Graph client does.

**Tech Stack:** Fastify 5, Drizzle ORM 0.45 + drizzle-kit, PostgreSQL 17, Zod 4, Vitest 4 · React 18, Vite 5, react-router-dom 6.

**Spec:** [`docs/superpowers/specs/2026-09-03-knowledge-base-design.md`](../specs/2026-09-03-knowledge-base-design.md)

## Global Constraints

- **Language.** Code, comments, commit messages and docs in English. Every string a user reads stays Russian — the frontend renders a server error's `message` verbatim.
- **Commands run from the repository root:** `npm --prefix server …`, `npm --prefix rakurs …`.
- **Server tests need the test database** on port 55432. A refused localhost connection reported as `connect EPERM` is the sandbox, not a broken test — run those commands with the sandbox disabled.
- **No test may reach the network.** The page fetcher is an interface; tests inject a fake.
- **No fixtures and no invented data.**
- **Role vocabulary:** `owner` and `member`. Writing and correcting an item is open to any member — an operator who spots a wrong answer is the fastest way it gets fixed. Importing, reimporting and deleting a source is owner-only.
- **An agent or a record the caller does not belong to answers 404, never 403.**
- **Any id taken from a URL is checked with `isUuid()`** before it reaches a query.
- **The searchable column is generated by Postgres,** never written by us. An item edited through any path is indexed correctly by definition.
- **Text search uses the `russian` configuration,** written once as a constant.

## Definition of done

- An item is found by a word from its content and by a stemmed form of that word.
- A query that matches nothing returns nothing, so the agent in stage 5 learns it cannot answer.
- An item belonging to another agent is never returned, and answers 404 by id.
- A pasted block splits on blank lines, each item taking its first line as a title; a block with nothing to split on becomes one item.
- A fetched page's headings become titles; a page without headings becomes one item.
- Reimporting a source replaces what it made and keeps what a person edited.
- A URL that is not http(s), does not answer HTML, never answers, or answers something enormous is refused with a Russian reason and creates nothing.
- No test reaches the network.
